# Contributing

Follow [WORKFLOW.md](WORKFLOW.md) for ownership, provenance, verification and
downstream migration checks. Agent instructions are in [AGENTS.md](AGENTS.md).

`HilbertMathlib/Foundation/` contains only paper-independent material.

Paper-specific formalizations belong in their own repositories and may import `HilbertMathlib`, never the other way around.

Before copying code from another repository, check its LICENSE and add an attribution header.
